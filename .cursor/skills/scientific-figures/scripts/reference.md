# pubstyle — design system reference

Shared style layer for every figure script in this skill.
Import it, call `set_pub_style()` once, then draw.

```python
from pubstyle import set_pub_style, PALETTES, savefig, style_axes, add_panel_label
set_pub_style()                     # house default, 9 pt
set_pub_style(theme="nature")       # journal preset
```

Everything below is additive: the original API (`set_pub_style`, `PALETTES`,
`out_dir`, `savefig`, `add_panel_label`, `style_axes`) keeps its old names,
defaults and behaviour, so the existing 50+ scripts are untouched.

Visual index of the whole system: `output/00_style_showcase.png`
(generated by `fig_00_style_showcase.py`).

## 1. Themes

`set_pub_style(base_font=9, theme="default", **overrides)`

| theme | base font | line width | axes rule | canvas | use it for |
|---|---|---|---|---|---|
| `default` | 9 pt | 1.6 | 0.8 | as given | everyday multi-panel figures, the look of this skill |
| `nature` | 7 pt | 1.1 | 0.6 | 3.5 × 2.6 in | Nature-family submissions; 7 pt is their type floor, rules are hairlines |
| `science` | 8 pt | 1.3 | 0.7 | 3.6 × 2.7 in | Science / AAAS; slightly larger type and darker ink than Nature |
| `ieee` | 7 pt | 1.0 | 0.7 | 3.3 × 2.4 in | IEEE two-column papers; inward ticks, tiny legends, narrow canvas |
| `presentation` | 13 pt | 2.6 | 1.2 | 10 × 5.6 in | slides and posters; readable from the back of the room, framed legend |

Notes

- Passing an explicit `base_font` always wins; the theme size is used only
  when `base_font` is left at its legacy default of 9.
- Themes set `figure.figsize`, so `plt.subplots()` without `figsize=` picks up
  the right canvas. Scripts that pass `figsize=` explicitly are unaffected.
- `constrained_layout` stays **off**; every existing script calls
  `fig.tight_layout()` and must keep working. The constrained-layout pads are
  pre-tuned if a new script opts in with `set_pub_style(**{"figure.constrained_layout.use": True})`.
- Extra rcParams can be injected per script:
  `set_pub_style(theme="ieee", **{"axes.grid": True})`. Like the original
  implementation, `set_pub_style` *updates* rcParams rather than resetting
  them, so an override stays active until it is overridden again. To render
  two themes in one process, scope them:
  `with mpl.rc_context(): set_pub_style(theme="nature"); ax = fig.add_subplot(...)`
  (axes must be **created** inside the context to inherit the theme).

Canvas sizes are also available as `FIGSIZES`:
`single (3.5×2.6)`, `single_tall (3.5×4.2)`, `double (7.2×4.5)`,
`double_tall (7.2×9.0)`, `square (4.6×4.6)`, `slide (10×5.6)`.

| name | type | colours |
|---|---|---|

| `cb_diverging` | diverging blue↔orange | `#0b3d63` `#2e6f9e` `#8fc0d9` `#f2f2f2` `#f4c48a` `#d98032` `#8c4a12` |
| `cb_diverging_pg` | diverging purple↔green | `#40004b` `#7b3294` `#c2a5cf` `#f7f7f7` `#a6dba0` `#3f8a4f` `#0d3d1f` |

| `cb_sequential_green` | sequential | `#f2f9f4` `#d3ecdb` `#a4d7b8` `#6bba8e` `#3d9469` `#1f6a47` `#0b3d2a` |
| `cb_sequential_warm` | sequential | `#fdf5ec` `#fbe0bf` `#f4c088` `#e69a54` `#cc722f` `#a04c18` `#66300c` |
| `cb_sequential_purple` | sequential | `#f7f4fa` `#e0d7ec` `#c1acd8` `#9c7dbe` `#77539f` `#54327a` `#331a4d` |
| `neutral` | greys | `#f5f5f5` `#d9d9d9` `#b3b3b3` `#808080` `#4d4d4d` `#262626` |

Picking rules

- Categories ≤ 8 → `cb_safe`; dense scatter or large fills → `cb_muted`.
- Never encode a red/green contrast as the *only* channel; use
  `cb_diverging` (blue↔orange) or add a shape/line-style channel.
- One ordered variable → a `cb_sequential_*` ramp. Signed variable centred on
  zero → a diverging ramp with the neutral colour pinned at 0.
- Baselines, "other" categories and reference lines → `neutral`.

Behaviour of `get_palette`

```python
get_palette("cb_safe")              # all 8 as-is
get_palette("cb_safe", 3)           # first 3, cycles if n > 8
get_palette("cb_sequential_blue", 5)  # interpolated to exactly 5 stops
get_palette("cb_diverging", 9, reverse=True)
get_cmap("cb_diverging")            # LinearSegmentedColormap for imshow/contourf
```

Sequential, diverging and `neutral` palettes are interpolated; categorical
palettes are cycled.

## 3. Function reference

| signature | what it does |
|---|---|
| `set_pub_style(base_font=9, theme="default", **overrides)` | apply global rcParams for a journal/medium preset |
| `set_cn_font() -> bool` | switch to Microsoft YaHei / SimHei / Noto CJK if installed; returns False silently if none found |
| `get_palette(name, n=None, reverse=False) -> list[str]` | n colours from a palette (interpolated or cycled) |
| `get_cmap(name, reverse=False, n=256)` | build a colormap from a palette |
| `set_color_cycle(name, n=None)` | make a palette the default `axes.prop_cycle` |
| `lighten(color, amount=0.5)` / `darken(color, amount=0.3)` | blend a colour toward white / black |
| `out_dir() -> str` | absolute path of the skill's `output/` folder (created if missing) |
| `savefig(fig, name, formats=("png",), dpi=None, close=True, transparent=False)` | write to `output/` in one or more formats, print each path, close the figure |
| `add_panel_label(ax, label, x=-0.12, y=1.05, weight="bold", size=11)` | one bold panel label in axes coordinates |
| `letter_panels(axes, labels=None, fmt="({})", start=0, x=-0.12, y=1.05, size=11, weight="bold", uppercase=False)` | stamp (a) (b) (c)… across a list/array of axes |
| `style_axes(ax)` | legacy L-shape trim: hide top/right, 3 pt ticks |
| `despine(ax, top=True, right=True, left=False, bottom=False, offset=None)` | hide any spines, optionally push the survivors outward |
| `annotate_box(ax, text, loc="upper left", ...)` | white rounded call-out box, the house style for statistics |
| `sig_stars(p, ns="n.s.") -> str` | `***` p<0.001, `**` p<0.01, `*` p<0.05, else `n.s.` |
| `add_sig_bracket(ax, x1, x2, y, text="*", height=None, color="#333333", lw=0.9, ...)` | significance bracket with a centred label |
| `add_colorbar(fig, mappable, ax, label="", orientation="vertical", fraction=0.046, pad=0.03, shrink=0.92, aspect=22, ticks=None, extend="neither")` | colorbar with hairline outline and small ticks |
| `smooth_line(x, y, frac=0.3, n=200, xmin=None, xmax=None)` | Gaussian-kernel LOWESS-style trend on a dense grid |
| `simulate_deuteranopia(color)` *(in `fig_00_style_showcase.py`)* | preview how a colour reads with red-green colour blindness |

### Usage examples

Vector export for submission:

```python
savefig(fig, "12_my_figure.png", formats=("png", "pdf", "svg"))
```

Significance annotation on a bar chart:

```python
p = 0.0004
add_sig_bracket(ax, 0, 2, y=ax.get_ylim()[1] * 0.88, text=sig_stars(p))
```

Statistics call-out:

```python
annotate_box(ax, f"$R^2$ = {r2:.2f}{sig_stars(p)}\nn = {n}",
             loc="lower right", weight="bold")
```

Trend line without statsmodels:

```python
xg, yg = smooth_line(x, y, frac=0.25)
ax.plot(xg, yg, color="#222222", lw=1.8)
```

Colorbar and colormap from a palette:

```python
im = ax.imshow(z, cmap=get_cmap("cb_diverging", reverse=True), vmin=-1, vmax=1)
add_colorbar(fig, im, ax, label="Anomaly")
```

Batch panel labels:

```python
fig, axes = plt.subplots(2, 3, figsize=FIGSIZES["double"])
letter_panels(axes)                       # (a) … (f)
letter_panels(axes, uppercase=True, fmt="{}")   # A … F
```

Chinese labels, with a safe fallback:

```python
if set_cn_font():
    ax.set_xlabel("时间 (小时)")
else:
    ax.set_xlabel("Time (h)")
```

> Default figures in this skill are **English-only**: matplotlib's DejaVu Sans
> has no CJK glyphs and renders tofu boxes.

## 4. What makes a figure look expensive

Checklist to run before saving.

**Structure**

- [ ] Top and right spines removed; remaining spines 0.6–0.8 pt in `#333`, never pure black.
- [ ] Ticks point outward, 3 pt long, 0.8 pt wide; no tick on an axis that carries no scale.
- [ ] Panel labels are consistent: bold `(a)` outside the axes, same offset in every panel.
- [ ] Every panel in a grid shares limits, ticks and colour meaning unless it truly cannot.
- [ ] Nothing is centred by accident — align titles, labels and call-outs to a common grid.

**Type**

- [ ] 7–9 pt everywhere; the smallest label is still ≥ 6 pt after scaling.
- [ ] Bold is rationed: panel titles and statistics only. No italics for emphasis.
- [ ] One typeface. Units in parentheses, `t ha$^{-1}$` style, not `t/ha`.
- [ ] Tick labels are short — rescale the data instead of printing `0.000012`.

**Colour**

- [ ] Low-chroma, slightly desaturated hues; never `#ff0000`, `#00ff00`, `#0000ff`.
- [ ] One accent colour carries the message; grey carries context.
- [ ] Sequential data uses a monotone-lightness ramp; signed data uses a diverging ramp centred at zero.
- [ ] Passes a colour-blindness check (`cb_*` palettes, or verify with `simulate_deuteranopia`).
- [ ] Fills sit at 0.15–0.25 alpha so overlapping bands stay readable.

**Data ink**

- [ ] No 3-D, no shadows, no gradients-as-decoration, no boxed legend when direct labels fit.
- [ ] Grid, if present, is `#d9d9d9` at 0.6 pt behind the data (`axes.axisbelow=True`).
- [ ] Scatter points get `edgecolors="none"` and alpha instead of heavy strokes.
- [ ] Error bars are thinner than the elements they annotate (0.8 pt, 2.5 pt caps).
- [ ] Reference lines (zero, threshold, 1:1) are dashed grey, drawn *under* the data.

**Finish**

- [ ] Statistics live in a white rounded box with a `#cccccc` hairline, not naked on the data.
- [ ] `fig.tight_layout()` (or constrained layout) called; nothing clipped, nothing overlapping.
- [ ] Saved at 300 dpi with `bbox_inches="tight"`; PDF or SVG alongside the PNG for submission.
- [ ] Opened the exported file and actually looked at it at 100 %.
